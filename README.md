# Ивановский аэроклуб — первый прыжок

Статический интерактивный сайт: пять мобильных чекпоинтов, плавный полёт, отдельная сцена приземления и форма заявки.

Публикация: GitHub Pages, ветка `main`, корневая папка. HTML, CSS и JavaScript не требуют сборки.

Форма отправляется обычным HTTPS POST в действующий приёмник Netlify Forms `jump-request`. После приёма Netlify показывает подтверждение отправки. Секретных ключей в клиентском коде нет.

Самолёт хранится в общей иллюстрации aircraft.svg; остальные SVG встроены в HTML.

29.10.2026: добавлен стартовый экран «Как играть» с анимацией свайпа и крупным объяснением управления. На телефоне — свайп вверх по небу, один жест на остановку. Повторное открытие кнопкой «Как играть» сохраняет текущий этап. На компьютере показывается инструкция для стрелок и точек маршрута. При reduced motion анимация отключена. Отправка заявки остаётся без изменений.

29.10.2026: две прежние иллюстрации самолёта заменены одной боковой проекцией в aircraft.svg. Исправлены пропорции фюзеляжа, крыльев, стоек, кабины, хвостового оперения и шасси. Анимируется только винт с помощью 2D scaleY; геометрия планера не трансформируется. Проверены пропорции картинки и отсутствие пересечения с парашютистом на мобильном экране.
